Understanding UDT on CKB

User Defined Tokens (UDT) on Nervos CKB are custom tokens similar to ERC-20 on Ethereum, but designed for CKB's unique Cell model. Unlike account-based chains, CKB uses UTXO-style Cells where token balances are stored in Cell data.

sUDT (Simple UDT)

The minimal standard defined in RFC-0025. Key features:

  • Token amount stored as 16-byte little-endian u128 in Cell data
  • Type Script args contain the owner lock hash (unique token ID)
  • Owner lock controls governance (mint, burn, etc.)
  • Simple and gas-efficient

xUDT (Extensible UDT)

Extended standard that adds flexibility through extensions:

  • Supply caps and minting limits
  • Pausable transfers for emergency stops
  • Regulatory compliance features
  • Custom extension data in Cell
