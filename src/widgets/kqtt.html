KQTT Protocol Specification

KQTT is a P2P adaptation of MQTT that operates over WebRTC DataChannels. It maintains MQTT semantics (topics, QoS, retain) while eliminating the need for a central broker.

Key Features

  • Serverless: No central broker required
  • P2P Mesh: Messages propagate through peer network
  • MQTT Compatible: Same topic/QoS/retain semantics
  • E2E Encrypted: DTLS over WebRTC
  • Offline First: Local message queue with sync

Message Format

{ "type": "PUBLISH", "topic": "konomi/line01/temp", "payload": "...", "qos": 1, "retain": false, "msgId": "uuid-v4", "from": "peer-id", "ts": 1703500935123 }
